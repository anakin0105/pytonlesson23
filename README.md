# Skystore

Учебный проект интернет-магазина товаров, разработанный в рамках курса по Django.

![Skystore](https://via.placeholder.com/800x300/667eea/ffffff?text=Skystore) <!-- можешь потом заменить на реальный скриншот главной страницы -->

## Описание

**Skystore** — это полноценный каталог товаров с админ-панелью, формой обратной связи, работой с медиа-файлами и выводом последних добавленных продуктов.

Проект выполнен в соответствии со всеми требованиями курса и демонстрирует современные практики разработки на Django 6.0.

## Установка и запуск

1. **Клонируйте репозиторий**:
    ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd django-22   # или название вашей папки
    ```
2. **Установите зависимости**:
    ```
    poetry install --no-root
    ```
3. **Активируйте окружение**:

    ```
   poetry shell
    ```
4. **Создайте файл .env в корне проекта и заполните**:

    ```
    SECRET_KEY=your_very_long_secret_key_here
    DEBUG=True
    NAME=skystore_db
    USER=postgres
    PASSWORD=your_password
    HOST=localhost
    PORT=5432
    ```
5. **Примените миграции:Bash**:

    ```
   python manage.py migrate
    ```
6. **Создайте суперпользователя:**:

    ```
   python manage.py createsuperuser
    ```
7. **Запустите сервер:**:

    ```
   python manage.py runserver
    ```
8. **Откройте в браузере: http://127.0.0.1:8000**:

Дополнительные команды

Загрузка тестовых данных через кастомную команду:
    ```
    python manage.py add_products
    ```


Загрузка фикстур (если используете):
    ```
    python manage.py loaddata catalog.json
    ```
